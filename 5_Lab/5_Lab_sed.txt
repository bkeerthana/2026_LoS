Exercise 14: Modifying a Security Configuration File

Create security.conf:

PermitRootLogin yes
PasswordAuthentication yes
MaxAuthTries 6
FirewallStatus disabled
LogLevel INFO
GuestLogin enabled

First make a backup:

cp security.conf security.conf.backup

Use sed -i to:

Change PermitRootLogin yes to PermitRootLogin no.
Change MaxAuthTries 6 to MaxAuthTries 3.
Change FirewallStatus disabled to FirewallStatus enabled.
Change LogLevel INFO to LogLevel VERBOSE.
Change GuestLogin enabled to GuestLogin disabled.

Use the safer backup form:

sed -i.bak 'sed-command' security.conf

This exercise demonstrates configuration editing only; it does not configure the actual system.
